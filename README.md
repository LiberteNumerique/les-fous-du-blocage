# Les Fous du Blocage

Site statique GitHub Pages. Contenu : `index.html`, `profils.json`, `analyse-donnees-publiques.xlsx`, `donnees-completes.csv`.

Pour publier : déposer tous ces fichiers à la racine de la branche `main`, puis Settings → Pages → Deploy from a branch → main → /(root).

Les données sont une photographie au 29 octobre 2026, pas une synchronisation temps réel. Vérifier les obligations de protection des données personnelles avant publication publique des fichiers nominatifs.
